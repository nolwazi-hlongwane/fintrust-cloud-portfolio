## About This Repository

This repository documents my work throughout the 16-week Cloud to Solutions Accelerator programme, run through Nedbank's FinTrust Cloud Learnership. Every exercise — SQL, Python, and AWS architecture — is built around a single evolving scenario: **FinTrust Bank**, a fictional South African digital bank moving its transaction-processing systems from on-premises infrastructure to AWS.

The programme runs on two parallel tracks each week:
- **AM sessions** — AWS cloud architecture and infrastructure (working toward the SAA-C03 exam)
- **PM sessions** — SQL and Python, applied directly to FinTrust's banking data model (customers, accounts, transactions)

This repo captures the PM-track deliverables (SQL scripts and Python code) plus written reflections on each week's AM/PM content. AWS console work (EC2, RDS, IAM, etc.) is conceptual/architectural in the early weeks and doesn't produce a code artifact until later weeks introduce `boto3` and infrastructure-as-code.
